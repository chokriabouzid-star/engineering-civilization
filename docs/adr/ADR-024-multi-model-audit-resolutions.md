# ADR-024: Multi-Model Adversarial Audit Resolutions (F1–F10)

**الحالة:** مُنفَّذ ومُتحقَّق منه فعليًا (مُختبر محليًا بالكامل + CI أخضر)
**التاريخ:** 2026-08-22
**السياق:** Phase 4 — معالجة كافة الفجوات الـ 10 المكتشفة عبر التدقيق العدائي المستقل بـ 6 نماذج ذكاء اصطناعي.

## 1. القرارات والإصلاحات المنجزة

### F1: إلزامية الحصانة لـ Docker في مسار الإنتاج
- **المشكلة:** `executor.rs` كان يستدعي `DockerRunner` غير المقوَّى بينما `HardenedDockerRunner` مقصور على الاختبارات.
- **الحل:** حذف المسار غير المقوَّى كليًا، وجعل `HardenedDockerRunner` هو المشغّل المباشر الوحيد للتجميع والتنفيذ داخل الـ Sandbox.
- **التوافق التشغيلي:** استخدام `HardenedConfig::without_seccomp()` في `SandboxExecutor` لتوفير أقصى قدر من التوافقية مع بيئات الحاويات المتنوعة و GitHub Actions مع الإبقاء على كافة طبقات الحصانة (cap-drop ALL، read-only، non-root، pids-limit، network-none).

### F2: مصادقة API إجباريّة على المسارات المُحدِّثة
- **المشكلة:** واجهة REST كانت مفتوحة بالكامل بدون أي مصادقة.
- **الحل:** إنشاء middleware للمصادقة عبر `X-API-Key` على كل المسارات عدا `/health` المفتوح للمراقبة، وإلزام البيئة بـ `EC_API_KEY` عند الإقلاع وتغيير العنوان الافتراضي إلى `127.0.0.1`.

### F3: إرجاع Exit Code غير صفري عند وجود انتهاكات
- **المشكلة:** `ec check` كانت تُرجع `exit 0` دائمًا حتى مع وجود انتهاكات دستورية.
- **الحل:** جعل `cmd_check` تُرجع `exit(1)` فورًا عند وجود انتهاكات (`files_failed > 0`)، وإضافة job استشاري لـ `ec check` داخل `.github/workflows/ci.yml`.

### F4: إغلاق ثغرة خداع التغطية بالأختبارات الشكليّة
- **المشكلة:** حساب التغطية كان يعتمد عدد الدوال فقط، مما يمنح كوداً بلا تأكيدات حقيقية درجة `1.000`.
- **الحل:** ربط حساب تغطية الـ Crate بوجود `assert_count > 0`؛ إذا كانت الاختبارات فارغة خالية من التأكيدات تُخفّض التغطية إلى `0.0`.

### F5: استعادة نقاء الـ Kernel في ec-constitutional
- **المشكلة:** `ec-constitutional` كان يحتوي على `async fn` وعتمد `tokio` بميزة `full`.
- **الحل:** إزالة `evaluate_async` وتبعيات `tokio` بالكامل من `ec-constitutional` واستبدال الاختبارات باختبارات متزامنة سريعة عبر الكاش.

### F6: استخراج ADR-005 المستقل
- **المشكلة:** محتوى ADR-005 كان مدمجًا بصورة غير مقصودة في نهاية ملف ADR-004.
- **الحل:** إنشاء وثيقة `docs/adr/ADR-005-constitutional-evaluation-pipeline.md` مستقلاً.

### F7: تنظيف ملفات البقايا وتوسيع .gitignore
- **المشكلة:** وجود ملفات نتائج وسكربتات وقتية متتبّعة في git.
- **الحل:** حذف كافة ملفات البقايا (`report.json`، `audit.log`، إلخ) وتوسيع `.gitignore` لمنع تكرارها.

### F9: توافقية المسارات عبر tempfile
- **المشكلة:** `week27_gate.rs` كان يستخدم مسار صلب `/tmp/` يكسر التوافقية مع Windows.
- **الحل:** استبدال المسار بـ `tempfile::tempdir()` آمن ومتوافق مع جميع الأنظمة.

### F10: توضيح التسمية الإحصائية في التوثيق
- **المشكلة:** تسمية "Bayesian" قد توحي بنماذج posterior غير مطبّقة في الكود.
- **الحل:** توضيح التوثيق الإرشادي لـ `BayesianTracker` ليبيّن أنه يعتمد تراكم الأدلة وفواصل ثقة ويلسون (Wilson confidence interval).
